## 4. بنود التنفيذ الحقيقي — أقل نطاق معقول

1. **24-B (أولًا):** اختبار قبول قصير على الواجهة الموجودة ومسارات الهوية والفلاتر والتصدير. إصلاح خلل مثبت فقط؛ وإلا لا تغييرات.
2. **24-C (أولوية برمجية عندما تجتاز B):** تصميم/تنفيذ **مسار مرشح، غير منشور** لبيانات إقرارات الموظف نفسه، لا يوسّع دور الموظف إلى الإحصاءات الإدارية. `readOwnCircularAcknowledgements` + `runOwnAcknowledgementReport` + `exportOwnAcknowledgementsExcel` هي نقطة البدء، لا إعادة بناء المصدر. اختبارات PostgreSQL مقيّدة بالمالك، سلوك HTTP على تركيب اختباري، الحسابات المتعارضة، والتصدير.
3. **24-D:** إثبات خطة نسخ PostgreSQL + المرفقات واستعادتهما في نسخة اصطناعية. حماية DB rollback وهجرة `0015`، وانتباه لقفل إنشاء الفهرس في قاعدة حية.
4. **24-E:** عينات PDF/XLSX عربية وملف Manifest للحاوية والخطوط؛ لا يمكن اعتماد المضيف/digest أو الترخيص من CI وحده.
5. **24-F:** تكامل ومراجعة للـdiff الجديد فقط وقرار `READY_FOR_PREPROD_REVIEW` مقابل `NO_GO`.
