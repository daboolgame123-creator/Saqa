## ما فُحص

- نموذج Domain `Transaction`، واتجاه الكتاب `صادر/وارد/داخلي`، والحالة `قيد المراجعة/مكتمل`، وتصنيف الكتاب وأولويته.
- التحقق من بيانات الإنشاء وPATCH، والتواريخ والحقول المشتقة، وملحقات الكتاب.
- اتساق `TransactionService` المحلي مع نوع البيانات والتعامل الرسمي على API.
- PostgreSQL `transactions` واشتقاق `month` من تاريخ الكتاب، والتحكم بالتزامن `expectedVersion`، والأرشفة الناعمة.
- التوجيه/الهامش الإداري، حقل التذكير الاختياري، وتاريخ الاستيراد الأصلي.
- البحث عن الكتب المشتبه بتكرارها، ومسارات تنبيه الكتب العامة وسجلات التدقيق.
- الاستعلامات المقيدة بالصلاحيات والاختبارات التراكمية على قاعدة اصطناعية.

## المشكلات المثبتة وإصلاحاتها

| الخلل | الخطر | الإصلاح |
|---|---|---|
| `reminder` كان يقبل أي كائن JSON | تخزين تذكير بلا `enabled` أو توقيت صالح أو نص | مُحقِّق كائن يفرض نوع الحقول والتاريخ مع منطقة زمنية، ويرفض الحقول الإضافية |
| `directorDirective` كان يقبل أي كائن JSON | بيانات هامش مكسورة أو نص/تاريخ غير صالح أو حقول غير معتمدة | تحقق صريح من النص والتاريخ و`actionRequired` |
| `readAt` و`importedAt` كانا يقبلان نصًا تعسفيًا | فشل تحويل PostgreSQL قد يتحول إلى HTTP 500 | تحقق ISO 8601 مع منطقة زمنية قبل SQL، ورفض 400 |
| `importedAt` كان قابلاً لتعديل PATCH عادي رغم استبعاده من واجهة الكتاب | تغيير تاريخ الاستيراد التاريخي بعد الإنشاء | لا يُقبل في PATCH؛ يبقى مقبولًا عند إنشاء استيراد تاريخي |
| فحص التشابه كان يقرأ كل النتائج ثم يقتطع 10 بعد الاستعلام | تكلفة قراءة/نقل غير محدودة للكتب المتشابهة | `LIMIT 10` ثابت داخل استعلام PostgreSQL نفسه |

## أشياء صحيحة مُتحقق من وجودها في الكود

- `direction` و`status` حقول منفصلة وقيمها مقيدة في الواجهة والـAPI و`CHECK` قاعدة البيانات.
- تاريخ الكتاب `document_date` منفصل عن `created_at` و`imported_at`، والشهر مشتق من التاريخ.
- `expectedVersion` إلزامي في PATCH، ورفض النسخة القديمة قبل الكتابة.
- الأرشفة إجراء soft-delete وليس حذفًا نهائيًا.
- نقل الحالة عبر `POST /:id/status` يكتب `status_change`؛ وبقاء `status` في PATCH العام **توافق مقصود وموثق في Phase 20**، فلم نغيّره إلى قاعدة أعمال جديدة.
- التذكير المخزن كبيانات داخل Transaction مختلف عن محرك الإرسال المجدول في Phase 21؛ لا نخلطهما أو نعدّهما نظاماً واحداً.
- إنذار التشابه تحذير غير حاجز لإنشاء الكتاب.
