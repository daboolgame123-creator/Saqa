- تصميم schema في `server/migrations/0001..0015`، فصل الجداول والمفاتيح الخارجية، قيد uniqueness وفهارس القراءة.
- سجل `schema_migrations`، checksum، الترقيات والتراجعات، `status`، وCLI مع `--confirm-destructive` وحظر التراجع الإنتاجي.
- اختبارات migrations UP/DOWN وCOMMIT/ROLLBACK وFK/UNIQUE والتعامل CRUD مع repositories.
- ملاءمة الترحيل 0016 في PR Phase1 كمرشح مستقل، ودمج المرشحين 1–9 تجريبيًا على قاعدة بيانات اصطناعية لا بيانات المستخدم.

## العيوب المثبتة وإصلاحها

| الخلل | الأثر | الإصلاح |
|---|---|---|
| تشغيل `runMigrations` و`rollbackMigrations` دون قفل متبادل | تعارض عمليتين على DDL وسجل الإصدارات، وقد تفشل إحداهما في منتصف الإجراء | قفل `pg_advisory_xact_lock` بنطاق المعاملة مشترك لـup/down على قاعدة البيانات نفسها |
| `rollbackMigrations(steps>1)` ينفذ كل خطوة بمعاملة منفصلة | فشل خطوة متأخرة يترك التراجع جزئيًا بعد إسقاط جداول/فهارس | معاملة واحدة تحوي كل خطوات `down`؛ أي خطأ يلغي **كل** الدفعة |
| `rollbackMigrations(steps)` يسمح بـsteps أكبر من عدد المطبّق | طلب خاطئ قد يُسقط كل المراحل المتاحة بدل التوقف | رفض فوري دون أي تغيير |
| `getMigrationStatus` لا يتحقق من checksum/الملفات المتفق عليها | قد يبدو سجل الترحيلات سليمًا رغم تعديل ملف مطبّق أو غيابه | `verifyApplied` قبل عرض الحالة، مع مطابقة اسم الملف وchecksum |
| ترتيب الملفات نصي لا رقمي | ملفات بأصفار متفاوتة قد تُطبق خارج الترتيب | ترتيب صريح حسب رقم النسخة |
| الترحيلات الأقدم المفقودة يمكن إضافتها بعد تطبيق ترحيل أحدث | تنفيذ `up` قد يخالف افتراضات الترحيلات اللاحقة | رفض تطبيق أي إصدار أقدم غير مُطبق إن كانت نسخة أحدث قد طُبقت |

## ما ثبت أنه صحيح ولم يُعدَل
- فصل `date` عن `timestamptz` عن أوقات العمل والدقائق، و`created_at` عن تاريخ الكتاب.
- `Pool` مُنشأ فقط عند الحاجة ولا يطبع رابط قاعدة البيانات، مع `client_encoding=UTF8` للعربية والأرقام الهندية.
- `withTransaction` يلتزم في النجاح ويرجع بالكامل بعد الاستثناء أو انتهاك UNIQUE.
- `cli down` محظور في `NODE_ENV=production` ويتطلب `--confirm-destructive` في غير الإنتاج.
- الاختبارات الأصلية تتحقق من كامل الجداول وقيود FK وUNIQUE، والترحيل والتراجع وإعادة البناء والاستيراد الصناعي.
