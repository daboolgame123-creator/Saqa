## 3. تدفق البيانات (Data Workflow)
1. **إدخال المعاملة**: يقوم مسؤول الذاتية بإنشاء المعاملة من خلال `NewTransactionModal` مع تحديد الرقم والتاريخ والتصنيف ورفع الوثائق.
2. **التخزين والحفظ**: تقوم خدمة `StorageService` بتسجيل المعاملة وتحديث الحالة محلياً.
3. **مراجعة المدير**: تظهر المعاملة كـ "غير مقروءة 🔴" في شريط التنبيهات وسجل المعاملات، حيث يطّلع عليها السيد المدير ويسجل هامشه وتوجيهه.
4. **الربط بالمنتسبين**: تقوم دوال `employeeUtils` بربط المعاملة بالمنتسب أو الباحث تلقائياً في `EmployeesView`.
5. **إصدار التقرير**: يتم تجميع بيانات الشهر تلقائياً في `MonthlyReportView` مع إمكانية استعراض وتدقيق المرفقات وطباعة التقرير.
