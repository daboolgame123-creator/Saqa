# نظام إدارة الذاتية والأرشفة والتوثيق الإداري (Zatiya Management System)

منظومة إدارية وأرشيفية رقمية متكاملة تهدف إلى رقمنة وأتمتة حركة الكتب الرسمية (الصادرة، الواردة، والداخلية)، وإعداد التقارير الشهرية، ومطابقة استمارات المواقف اليومية، وإدارة سجلات المنتسبين والباحثين بدقة عالية.

---

## 🚀 المميزات والقدرات الأساسية

- **معاينة الوثائق والمرفقات بنقرة واحدة**: عارض صور عالي الدقة يتيح التكبير والتدوير والطباعة لكافة المستخدمين والمدير مباشرة من أي جدول أو تقرير.
- **نموذج الموقف اليومي المعتمد**: مطابق للنموذج الورقي الرسمي للمركز (الدوام الدائم، المتطوعين، الأجراء، الساعات، والإيفادات).
- **أضابير المنتسبين والباحثين**: سجل مفصل لكل كادر مع تاريخ المعاملات وإمكانية فك الارتباط المباشر لحفظ دقة الأضابير.
- **تبديل الأدوار الإدارية**: واجهة مخصصة للسيد المدير (تنفيذية وإحصائية) وأخرى لمسؤول الذاتية (أرشفة وتحرير وتدقيق).
- **دعم الوضع الليلي والنهاري (Dark / Light Mode)**: توافق بصري كامل مع مراعاة راحة العين أثناء العمل المطول.

## 🛠️ التشغيل والتطوير (Getting Started)

```bash
# تثبيت الحزم والمكتبات
npm install

# تشغيل بيئة التطوير
npm run dev

# فحص الأنواع البرمجية (Type Check)
npm run lint

# بناء نسخة الإنتاج النهائية
npm run build
```
